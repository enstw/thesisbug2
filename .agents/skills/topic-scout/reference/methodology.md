# 選題方法論（topic-scout deep reference）

選題不是把興趣改寫成標題，而是把模糊興趣轉換成可被資料回答、可被文獻定位、可在
篇幅內完成的研究問題。AI 不應只問「使用者想寫什麼」，而要協助判斷「這個題目是否
已經具備研究條件」。

## 主題不等於研究問題

模糊主題只能指出關注領域，不能直接支撐學術寫作。每個候選題目都要從主題推進到問題
意識：

- **主題**：灰色地帶衝突、半導體安全、美中科技戰、台海危機。
- **研究問題**：中國灰色地帶行動如何改變台灣嚇阻策略？美國出口管制如何重塑台灣在
  美中科技競爭中的戰略角色？

若候選題目只能回答「發生了什麼」，通常仍停留在描述層次；若能回答「為何發生」「如何
產生影響」「在何種條件下有效或失效」，才接近可研究題目。

## 好題目通常來自 puzzle

優先尋找能形成問題張力的題目，而不是只整理熱門議題。常見 puzzle 來源：

- **政策預期與結果不一致**：政策原本要達成某效果，但實際結果不同。
- **理論解釋不足**：既有理論能解釋一般案例，但對特定案例不足。
- **案例出現反常**：案例表現與常識或既有文獻預期不同。
- **新事件挑戰舊框架**：新技術、新衝突型態或新政策使既有分析框架需要調整。
- **文獻忽略特定面向**：例如忽略台灣視角、戰略後果、制度條件或時間變化。

若找不到 puzzle，題目仍可做為整理型作業，但不宜直接升級為 thesis 或 journal 題目。

## 題目生成公式

候選題目應盡量包含五個構件：

```text
研究題目 = 研究對象 + 時間範圍 + 問題意識 + 分析機制 + 可取得資料
```

檢查方式：

- **研究對象**：國家、區域、政策、組織、事件或制度是否明確。
- **時間範圍**：是否能說清楚起訖點，或至少說明為何選這段時間。
- **問題意識**：是否存在可分析的疑問，而非只有議題介紹。
- **分析機制**：是否初步知道要觀察因果機制、政策過程、戰略互動或制度變化。
- **可取得資料**：是否有學術文獻、政策文件、一手資料、事件資料或可信二手資料可用。

例：

```text
不佳：美中科技戰與台灣
較佳：2022 年後美國半導體出口管制如何重塑台灣在美中科技競爭中的戰略角色？
```

## 從興趣到候選題目的操作步驟

- **興趣拆解**：把使用者興趣拆成行為者、場域、事件、政策、概念與時間。
- **上位概念定位**：判斷題目屬於嚇阻、強制外交、聯盟政治、灰色地帶衝突、科技
  安全化、地緣經濟等哪一類討論。
- **問題句生成**：至少產生 3 個「為何」「如何」「在何種條件下」形式的研究問題。
- **範圍收斂**：固定時間、案例、政策或機制，刪除無法在目標篇幅內完成的部分。
- **初步證據檢查**：用少量搜尋確認是否找得到核心文獻與資料，再決定是否保留題目。

## 題目成熟度判斷

每個候選題目可先標示成熟度：

- **興趣層**：只有領域或事件，尚不能進入文獻搜尋決策。
- **主題層**：已有研究對象與範圍，但問題意識仍不清楚。
- **問題層**：已有可分析的研究問題，可設計搜尋策略。
- **題目層**：已有研究問題、範圍、初步文獻與可行資料，可進入題目評估矩陣。

Preparation 的目標是把至少 2–5 個候選方向推進到「問題層」，再用文獻搜尋與評估矩陣
判斷哪些能進入「題目層」。

## 新聞訊號驅動的矛盾式選題法（`/topic_discovery`）

當使用者只提供幾個大領域，AI 可先進行「topic discovery」，用近期新聞、政策文件與
智庫材料尋找問題訊號，再把訊號轉換為候選題目。此流程借用 TRIZ 的核心精神：好問題
常來自系統內部的矛盾，而不是單純來自熱門事件。新聞材料只負責發現 puzzle，不直接
決定題目。

工作流：

1. **領域輸入**：使用者提供 3–5 個大方向（灰色地帶、半導體安全、AI 軍事化、認知
   作戰、台海危機…）。
1. **新聞與政策訊號掃描**：搜尋最近 6–24 個月的新聞、官方文件、國會或立法院資料、
   智庫報告與重要專家評論。
1. **訊號分類**：政策轉向、戰略矛盾、技術變化、軍事事件、制度缺口、國際反應或輿論
   爭議。
1. **TRIZ 式矛盾抽取**：找出「同時想要 A 又不能犧牲 B」的張力，例如安全 vs 效率、
   嚇阻 vs 升高風險、自主 vs 聯盟依賴、透明 vs 保密、去風險 vs 成本、創新速度 vs
   管制能力。
1. **候選題目生成**：每個大領域至少 2–3 個候選題目，總數原則上不少於 5 個。
1. **初步可行性篩選**：對每個候選題目標示研究問題、新聞觸發訊號、核心矛盾、可能
   理論框架、可用資料與主要風險。

輸出格式至少包含：候選題目（一句話題名，避免預設結論）、研究問題（為何/如何/在何種
條件下）、新聞觸發訊號（關鍵事件+來源連結）、核心矛盾（TRIZ 式張力）、可能理論框架、
可用資料、主要風險。輸出是「候選題目池」，不是最終題目；完成後必須進入搜尋策略與
評估矩陣才能決定是否保留。

## 五階段流程細節

### Phase 1：建立候選題目
每個候選題目至少記錄：暫定題名、研究問題（為何/如何/在何種條件下）、研究對象與範圍、
初步重要性（學術/政策/戰略）、主要風險（資料不足/範圍太大/題目太常見/概念不清）。

### Phase 2：設計搜尋策略
至少包含：中文關鍵詞（台灣學術/政策用語、可能兩岸譯名）、英文關鍵詞（核心概念、案例、
理論、政策術語）、布林查詢式（如 `"grey zone" AND Taiwan AND deterrence`）、來源類型
（學術資料庫、圖書館、政府文件、智庫、新聞/事件資料庫）、篩選條件（年份、地區、語言、
出版類型、是否同儕審查）。

### Phase 3：蒐集與下載文獻
文獻分層：核心學術文獻（期刊/專書/學位論文/權威章節）、政策與一手資料（政府報告/國會
聽證/官方戰略文件/條約法規）、智庫與專家報告（政策脈絡/事件整理/近期討論）、新聞與
資料庫（僅用於事件時間線、引述公開發言或補背景，不作主要理論根據）。取得、儲存與
landing-page/CDN 處理交給 **source-kit** skill。

### Phase 4：摘要與評估文獻
每筆核心文獻至少記錄：研究/政策問題、方法或材料來源、核心論點、可引用頁碼或段落、
可用於本文的位置（背景/理論/案例/方法/反方/限制）、與其他文獻關係（互補/對立/延伸/
重複/無關）。只提供背景常識者標「背景」即可，不要硬升級為核心文獻。

### Phase 5：決定題目與下一步
題目決策包含：建議採用題目、研究問題定稿、範圍界定（時間/地區/案例/概念邊界）、暫定
論點或假設（證據不足則明確標示待驗證）、文獻缺口、下一步 work type
（`journal`/`thesis`/`homework`/`presentation` 或繼續 `preparation`）。

## 題目評估矩陣

每個候選題目用下列標準評估，避免只依興趣或直覺決策。

| 標準 | 高 | 中 | 低 |
| :--- | :--- | :--- | :--- |
| 文獻可得性 | 已有足夠核心文獻與全文 | 文獻存在但全文或關鍵資料不足 | 搜尋後仍缺少可信來源 |
| 研究問題清晰度 | 可形成明確問題與變項關係 | 主題清楚但問題仍需收斂 | 只有領域或事件名稱 |
| 戰略重要性 | 能連到安全、地緣政治或軍事戰略 | 重要性存在但需補論證 | 主要是描述性或技術性問題 |
| 範圍控制 | 可在目標篇幅內完成 | 需要刪減案例或時間範圍 | 題目過大或材料分散 |
| 原創空間 | 可找到明確文獻缺口或新案例 | 可做整理型或應用型貢獻 | 已被大量重複且難有新意 |

決策規則：

- 至少三項為「高」且沒有「低」：優先保留。
- 有一項「低」但可修正：標示待查並補搜尋。
- 兩項以上為「低」：排除或大幅改題。

## 常見失誤與修正

- **題目太大**（涵蓋多國/多年/多制度/多理論）→ 先固定一個案例、一段時間或一個機制。
  例：把「美中科技戰」收斂為「2022 年後美國半導體出口管制對台灣安全角色的影響」。
- **文獻只有新聞**（查得到事件但缺學術論點）→ 把新聞降為事件材料，另找理論文獻或
  政策研究支撐分析框架。
- **關鍵詞太窄**（結果很少或只找到同一類材料）→ 加入上位概念、同義詞、相鄰理論與
  不同譯名。例：灰色地帶可同時查 `grey zone`、`gray zone`、`hybrid warfare`、
  `coercion`、`salami slicing`。
- **過早定論**（題目一開始就含結論，如「證明某政策失敗」）→ 改成開放式研究問題，
  如「某政策在何種條件下削弱或強化嚇阻效果」。
