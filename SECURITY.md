# Security policy

## Supported versions

thesisbug2 has no releases yet. Security fixes are made on `main` only.

## Reporting a vulnerability

Please report privately through GitHub: **[Report a vulnerability](https://github.com/enstw/thesisbug2/security/advisories/new)**.

Do not open a public issue for a security problem. A public issue discloses the problem to everyone before a fix exists.

What is in scope: the framework's scripts and agent skills — for example a script that can be made to write outside the course repository, a skill instruction that leads an agent to leak local files or credentials, or an unsafe fetch in the source-acquisition tooling.

What to expect: this is a single-maintainer project. You should get an acknowledgement within a week, and a fix or a stated plan within 30 days for confirmed issues.
