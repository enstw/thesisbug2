# AGENTS.md

This is the course repository for **{{COURSE}}**. Coursework lives here; the thesisbug2 framework is mounted read-only at `.framework/`.

At the start of every agent session, run `./fw update` from this course root
before coursework, because shared instructions and tools must be current.
It updates the thesisbug2 submodule and commits only its version pin locally;
it does not push. If it fails, report the failure and continue with the
available checkout without resetting, stashing, or discarding local work.

Then read these, in this order, including the newly updated framework guide:

1. [`.framework/docs/AGENT-GUIDE.md`](.framework/docs/AGENT-GUIDE.md) — how to work in a course repo: layout, the `./fw` commands, skills, the two source tiers, and the communication contract.
1. [`COURSE.md`](COURSE.md) — this course: instructor, citation style, what is graded, schedule.
1. [`STATUS.md`](STATUS.md) — one line per unit, and which unit is current.

Course-specific agent instructions go below this line; they take precedence over the framework guide.
